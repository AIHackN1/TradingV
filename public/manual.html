종목 추가알람내 지표 추가지표 5선그리기백업문제 해결

1. 관심종목 추가·제거

  1. 왼쪽 관심종목 옆 +를 누릅니다. 휴대폰에서는 상단의 가로 관심종목 영역에 있습니다.
  2. 암호화폐는 Binance 현물 · USDT를 고르고 ADA 또는 ADAUSDT를 입력합니다. 선물은 기본 목록의 SOXLUSDT.P·BTCUSDT.P·ETHUSDT.P 3종을 선택합니다. 다른 거래소 선물은 지원하지 않습니다.
  3. 미국 주식은 미국 주식 · USD 일봉을 고르고 NVDA, QQQ, SOXS 등을 입력합니다. TradingView 거래소를 NASDAQ/NYSE/AMEX 중 정확히 선택합니다.
  4. 시세 확인 후 추가를 누릅니다. 공급자 조회에 성공한 종목만 저장합니다. 실패 시 티커를 확인하고 다시 시도합니다. 최대40개를 추가할 수 있습니다.
  5. 목록에서 종목을 선택합니다. 자체 미국 주식 분석·알람은 정규장 일봉만 지원하며 Yahoo Finance 데이터는 지연될 수 있습니다. 분봉은 TradingView 보기에서 확인합니다.
  6. 추가한 종목은 같은 + 관리 창에서 제거합니다. 관련 알람(중지된 알람 포함)이 있으면 먼저 삭제해야 합니다. 기본 종목은 유지됩니다.
관심종목·지표·그림·알람은 현재 브라우저에 저장됩니다. 기기나 브라우저가 달라지면 자동 동기화되지 않으므로 백업을 사용하세요.

선물 3종과 시세 구분

기본 목록의 SOXLUSDT.P · BTCUSDT.P · ETHUSDT.P는 Binance USDT 무기한 선물입니다. SOXL 주식 및 BTC/ETH 현물과 별도 종목·그림·알람으로 저장합니다. 공식 TradingView 보기에는 BINANCE의 .P 종목을 사용하며, 자체 분석은 Binance Futures 공개 REST/시장 WebSocket을 사용합니다. 제공자가 지역 제한을 반환하면 시세와 알람을 만들지 않고 오류를 표시합니다. 현물·주식 가격으로 대체하지 않습니다. 이 경우 공식 TradingView 차트를 여는 버튼을 사용할 수 있지만 자체 지표가 그 위젯 위에 표시되는 것은 아닙니다.

2. 알람을 정확히 설정하는 방법

  1. 차트의 알람 만들기 → 종목 → 시간봉 → 조건을 선택합니다.
  2. 가격 조건은 기준값, EMA 교차는 빠른/느린 기간, RSI는 기준값을 입력합니다. 보조지표 알람은 아래 고정 계산기간을 사용합니다.
  3. 한 번 울린 뒤 자동 중지를 켜면 최초 신호 후 중지됩니다. 끄면 조건을 다시 교차할 때마다 울립니다.
  4. 저장하면 현재 봉 이후를 감시합니다. 과거 신호를 생성 시점에 재생하지 않습니다. 등록 후 감시 첫 조회가 늦어져도 등록 이후 닫힌 봉은 검사합니다.
  5. 알람 기록에서 감지 시각(KST), 종목·시간봉, 확정 종가, 봉 시작(UTC)을 확인합니다. 최근500건 보관, 화면은 최근100건, CSV로 전체 보관분을 내보낼 수 있습니다.

시세는 대체로15초 간격으로 감시하므로 봉 마감 즉시 도착을 보장하지 않습니다. 같은 봉은 중복 기록하지 않으며 연결 회복 시 수신된 봉 범위에서 누락을 검사합니다. 시세 조회가 실패하면 감시 상태에 연결 오류를 표시합니다. 조회 도중 CSV로 전환하거나 알람을 중지·삭제해도 뒤늦게 도착한 응답으로 알람이 발생하지 않도록 상태를 다시 확인합니다. CSV 분석 중에는 해당 종목의 감시 중지 상태를 표시하며 다른 종목 알람은 계속 감시합니다.

TradingView 서버 알람과 다른 점: 현재 앱 알람은 페이지가 열려 있는 동안 브라우저에서 실행됩니다. 창 종료·아이폰 화면 잠금·절전·백그라운드 정지 중 감시는 보장되지 않습니다. 재접속하면 새 세션을 시작하여 이전 종료 중 신호는 재생하지 않습니다. 24시간 서버 감시·메일·Telegram·웹훅 전달은 아직 없습니다.

알림과 사운드 점검

알람 센터에서 브라우저 알림 켜기로 권한을 허용하고 사운드를 켠 뒤 알림 전달 테스트를 누릅니다. 테스트 문구는 실제 시장 신호가 아니며 알람 기록에 섞이지 않습니다. iOS는 홈 화면에 설치한 웹앱 등 브라우저·OS 조건에 따라 시스템 알림 지원이 달라집니다. 앱 내 토스트와 시스템 알림은 별개입니다.

내 지표 추가 · 파일 지원 범위

  1. 내 지표 · 그리기 → 내가 추가한 지표 → 지표 추가를 누릅니다.
  2. 이름, EMA/SMA, 가격 소스, 빠른/느린 기간을 입력하고 저장합니다. 두 선과 확정봉 LONG/SHORT 교차 마커가 같은 분석 차트에 표시됩니다.
  3. 추가한 지표의 시그널마다 알람을 누르면 현재 종목·시간봉에서 이후 시그널을 반복 감시합니다. 실제 시세 연결 후 등록하며 샘플/CSV/공식 위젯에서는 등록하지 않습니다.
  4. 설정 변경은 기존 알람을 변경하지 않습니다. 변경된 설정으로 감시하려면 기존 알람 중지 후 새로 등록하세요. 표시만 끄면 알람은 유지됩니다. 제거하려면 관련 알람부터 삭제합니다.

JS만 받는 기능이 아닙니다. 간편 편집기 또는 tradingv-indicator JSON을 사용합니다. 상세 JSON은 EMA/SMA 1~8선과 교차 시그널 최대4개를 지원하며 사용자 지표는 최대12개입니다. 예제 JSON 다운로드. 임의 Pine/JS 실행, APEX 전체 전략 변환, 수익성 검증 기능은 아닙니다.

공식 TradingView iframe에는 이 지표가 표시되지 않습니다. 자체 분석 차트에 추가되는 기능이며 ATH식 단일 Advanced Charts 통합은 아직 미완료입니다. 설정 가져오기는 기존 EMA구름대/전체 백업용이고 사용자 지표 추가와 별개입니다.

3. 공개식 보조지표 5선

내 지표 · 그리기 → 공개식 보조지표 5선에서 개별 표시를 켭니다. 표시 설정은 자동 저장됩니다. 모두 자체 분석 차트의 입력 봉으로 계산하며 외부 TradingView 위젯 위에는 표시되지 않습니다.

지표설정·계산읽는 방법
볼린저 밴드종가 SMA20 ± 편향 표준편차20 ×2변동성 범위와 확장/수축. 밴드 돌파만으로 반전을 단정하지 않음.
돈치안 돌파 채널현재 봉을 제외한 이전20봉 최고·최저직전 구간 돌파 여부. 현재 봉을 포함하는 일반 돈치안 표시와1봉 차이.
슈퍼트렌드Wilder RMA ATR10, 배수3ATR 기반 추세선·확정 방향 전환. 초반 ATR 준비기간은 표시하지 않음.
세션 VWAPUTC 날짜별 누적(HLC3 ×거래량)/누적거래량암호화폐 당일 평균 거래가격의 봉 기반 근사. 일봉·주식은 표시 안 함. 최초 일자의 수신 이력이 불완전하면 그 날 값도 불완전.
거래량 프로파일 근사최근200봉, 24가격구간, 각 봉의 고저범위에 거래량을 균등 분배가격대별 거래량을 오른쪽 가로막대로 표시. 실체결·호가·하위봉 프로파일이 아니며 화면 이동 범위가 아닌 최근200봉 기준.

이 5개는 성과 검증된 수익률 순위가 아니라 서로 다른 분석 용도를 고른 모음입니다. ATH 앱에서 Atropos·Cluster·Hexagon·Diamond·Cloud Bands 추천과 Volume profile 등의 목록을 확인했으나 잠금 원본 수식은 공개되지 않았습니다. 위 지표는 공개 계산식을 독립 구현한 것이며 ATH 복사본이 아닙니다.

APEX 점수필터와 반복 시그널 알람

  1. 실제 시세가 연결된 현물/선물의 1분·5분·15분·1시간봉을 선택합니다.
  2. APEX 점수필터 시그널에서 최소 점수60, CI49 미만, 터널/ATR1, 신호 대기8봉을 조절하고 시그널 설정 적용을 누릅니다.
  3. 이 시그널마다 알람을 누르면 이후 확정봉의 LONG/SHORT마다 반복 감시합니다. 같은 봉은 중복 알림하지 않습니다. 알람 센터의 활성화 토글로 중지합니다.
  4. 알림 권한·사운드를 켜고 전달 테스트를 합니다. 표시 체크를 꺼도 이미 등록된 알람은 계속 감시합니다. 알람은 등록 당시 설정의 사본입니다. 설정을 바꿨다면 기존 규칙을 중지하고 새로 등록하세요.

원본 Pine의 직전 확정 1시간·4시간 EMA155/162 레짐, 방향 점수·거래량Z·델타·촙 점수, CI·터널 폭·반대 스파이크 필터를 이식했습니다. 각 상위 시간봉162개 이상이 준비되어야 신호를 만듭니다. 대기 봉수는 실제 주문 체결 대신 표시 시그널 기준입니다. 포지션·분할청산·손절 후 방향차단·브레이커를 포함한 원본 전체 전략과 동일하지 않습니다. 차트 마커와 알람이 같은 함수를 사용하지만 TradingView 원본과 동일 시세로 수치 대조는 남아 있습니다.

선택 후보마다 알람은 아래 ASGMA·스윕·스파이크 중 체크된 후보를 묶어서 감시합니다. 점수필터 전 후보이므로 더 자주 발생할 수 있습니다. 같은 봉의 여러 후보는 한 기록에 방향과 이유를 함께 표시합니다. 과거 마커는 등록 즉시 재생하지 않습니다.

기존 APEX

4색 EMA구름대와 ASGMA·WhaleFlow 유동성 스윕·ATR스파이크 후보는 보관된 APEX v1.7 원본 기반입니다. 기간/색상은 지표 스튜디오에서 수정 후 차트에 적용합니다. HTF·점수 게이트 일부는 위 점수필터 엔진에 이식했으며 포지션·청산을 포함한 전체 전략 이식은 미완료입니다. JSON 가져오기는 EMA설정/백업용이며 Pine 직접 실행이나 임의 코드를 실행하는 기능이 아닙니다.

4. 그리기와 가격축

왼쪽 도구에서 선/도형 선택 → 시작점과 끝점 클릭. 수평·수직선은1회 클릭, 자유곡선은 누른 채 이동합니다. 선택 도구에서 그림 또는 기준점을 드래그하여 편집합니다. Delete삭제, Ctrl+Z되돌리기, Ctrl+Shift+Z다시 실행. 그림은 종목·시간봉별로 저장합니다.

축이 이상하거나 멀리 이동했다면 차트 오른쪽 위 최근 구간 · 가격축 초기화를 누릅니다. 최근140봉과 가격축 자동맞춤을 복원합니다. TradingView 공식 보기의 그림은 외부 위젯의 기능이며 자체 그림 백업과 별개입니다.

5. 백업·복원

상단 다운로드 아이콘으로 전체 백업JSON을 저장합니다. EMA구름대 설정·APEX 점수필터 설정과 표시·보조지표 표시·사용자 지표 라이브러리·추가 종목·알람·그림이 포함됩니다. 다른 기기에서는 설정 가져오기 → JSON/백업 파일 선택 → 설정 가져오기를 사용합니다. 알람은 중지 상태로 복원되므로 조건을 확인한 뒤 켜세요. 알람 기록은 원래 브라우저에 남으며 CSV로 따로 내보내 보관하세요. 외부 위젯 그림은 복원되지 않습니다.

6. 문제 해결

  • 알람이 안 울림: 활성화·종목·시간봉·새 확정봉·교차 여부를 확인하세요. 이미 기준 위에 있다는 이유만으로 울리지 않습니다. 앱을 열고 시세 연결 상태를 확인하세요.
  • 주식 티커 추가 실패: 미국 티커인지, 공급자 조회가 가능한지 확인하세요. 시세 공급자가 실패하면 저장하지 않습니다. CSV고정자료는 실시간 감시에 사용하지 않습니다.
  • 값이 TradingView와 다름: 거래소(현물/선물), 지연, 정규장/시간외, 수신 봉 수, EMA 초기화, 날짜 경계가 다를 수 있습니다. 원본과 같은 값/성과라고 검증되지 않았습니다.
  • 권한은 허용했는데 iPhone 시스템 알림이 안 뜸: 현재 브라우저 지원 범위와 iOS 홈화면 웹앱 조건을 확인하세요. 이 앱은 아직 서버에서 푸시를 보내는 서비스가 아닙니다.
