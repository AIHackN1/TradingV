# 단일 차트 통합 상태 (2026-10-23)

## 완료 기준

사용자 목표는 ATH 같은 한 차트에서 왼쪽 그리기·사용자 지표·시그널 알람을 함께 쓰는 것이다. 외부 공식 위젯과 자체 분석 탭은 최종 통합 완료가 아니다.

## 지금 실행 가능한 부분

- 자체 분석 차트에서 현재 APEX 부분 이식, 그리기, 공개식 보조지표, 사용자 이동평균 지표와 반복 알람을 같은 OHLCV/계산 함수로 처리한다.
- 사용자 지표는 EMA/SMA 1~8선, 가격 소스 7종, 교차 시그널 최대4개를 선언하는 데이터 JSON이다. 간편 편집기는 두 이동평균과 상·하향 교차를 생성한다. 최대12개 보관한다.
- 차트의 선과 확정봉 마커, 알람의 봉/방향 판정은 `src/custom-indicators.js`를 공유한다. 알람은 등록 당시 지표를 별도 복사하므로 나중에 표시·설정을 변경해도 규칙이 몰래 바뀌지 않는다.
- 이 기능은 Pine 컴파일러나 임의 JS 실행기가 아니다. 첨부 APEX 원본 파일은 보존하며 원본 전체 전략을 실행한다고 표시하지 않는다.

## 차트 엔진의 실제 차단 사유

1. ATH에서 이전 실화면 조사로 Charting Library v32.2 경로를 확인했지만 사용권과 전체 앱/지표 소스를 확보한 것은 아니다.
2. TradingView 공식 문서의 Get started는 승인 후 비공개 공식 GitHub 저장소에서 받아야 하며, 제3자 배포본을 사용하거나 공개 저장소에 재배포하면 안 된다고 명시한다. 따라서 ATH에서 라이브러리를 복사해 우리 앱에 배포하는 경로는 사용하지 않는다.
3. 공식 제품 FAQ는 개인 사용·취미·공부·테스트에 Advanced Charts/Trading Platform을 제공하지 않는다고 안내한다. 공개 서비스로 신청할 수 있는지와 실제 사용 조건은 TradingView 승인이 필요하다. 신청 승인/약관 수락을 이미 받았다고 간주하지 않는다.
4. 무료 iframe에는 사용자 Pine/전략 주입이 없다. 캔버스를 위에 덮고 외부 위젯의 시세·좌표를 추출해 통합을 흉내 내지 않는다.

## 데이터와 알림의 별도 차단 사유

- 기존 Vercel 운영 함수에서 Binance 선물 공개API가 HTTP451을 반환한다. 같은 거래소의 현물·SOXL ETF 일봉을 선물이라고 바꿔 표시하지 않는다. 공식 위젯의 선물 보기와 자체 선물 지표 감시는 별개다.
- Advanced Charts 자체에도 TradingView 데이터/서버 알람은 포함되지 않는다. 정식 엔진을 확보한 이후에도 허용된 선물 시세 공급자를 연결해야 한다.
- 창 종료·화면 잠금 후 전달을 위해 영속 저장소·서버 감시 실행·기기별 푸시 구독·중복방지/재시도 검증이 필요하다. 현재 앱은 브라우저 감시이며 서버 감시라고 표시하지 않는다.

## 다음 작업 순서

1. 승인된 차트 라이브러리/사용 조건과 허용된 선물 데이터 공급자를 확보한다. 개인 용도라 정식 라이브러리 제공 대상이 아니면 그 조건을 숨기지 말고 오픈소스 엔진으로 같은 사용 흐름을 구현하는 방향을 사용자와 확정한다.
2. 현재 분리된 순수 지표 평가기를 단일 차트의 데이터피드/사용자 스터디와 연결하고 줌·가격축·도구·종목/시간봉 전환을 실브라우저에서 검증한다.
3. 계정/기기와 연계되는 영속 알람 저장·스케줄 실행·백그라운드 전달을 배포 환경에서 끝까지 검증한다.
