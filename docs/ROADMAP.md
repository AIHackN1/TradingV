- [ ] 서버에 저장되는 24시간 알람이 필요하면 영속 저장·스케줄러·중복 방지·전달을 설계하고 실행 증거로 검증. 구현 전에는 창 닫아도 감시된다고 표시하지 말 것.

## 표면을 구분할 것

- TradingView 보기: 공식 외부 위젯. SOXL 및 암호화폐의 공식 내장 차트 옵션/그리기. 앱 APEX 구름대·알람 계산에 이 위젯 데이터를 사용하지 않는다. 위젯 그림 저장은 제공자 지원 범위.
- 내 지표·그리기: Lightweight Charts에 자체 EMA·RSI·도형·알람. 암호화폐는 Binance 현물. SOXL 자체 분석은 별도 Yahoo 일봉 어댑터가 있으나 공급자가 실패하면 차단 사유 표시.
- CSV: 정적 분석용 고정자료. 현재 종목/시간봉으로 가져오고 자체 지표와 그림을 적용. 실시간 알람/시세로 표시하지 않는다.

한 번에 남은 항목 하나를 실제 완료하고 테스트·검증·Git 반영·배포 결과와 남은 작업을 PROGRESS.md에 기록한다. 완료 항목을 반복해서 재구현하지 않는다.
